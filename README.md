یک کلاینت SSH و SFTP متن‌باز برای ویندوز، ساخته‌شده با Electron. مناسب کاربرانی که برای اتصال به سرورهایشان از پراکسی (مثل V2Ray/Xray) استفاده می‌کنند و یک رابط کاربری فارسی و ساده می‌خواهند.

![سفارشی‌سازی](https://img.shields.io/badge/رابط-فارسی_راست‌چین-blue) ![پلتفرم](https://img.shields.io/badge/پلتفرم-ویندوز-success) ![لایسنس](https://img.shields.io/badge/لایسنس-MIT-green) ![نسخه](https://img.shields.io/badge/نسخه-1.1.0-blue)

## امکانات

- **چند تب همزمان** — اتصال به چند سرور در یک پنجره، هر کدام یک زبانه‌ی ترمینال مستقل (xterm.js)
- **مدیریت سرورها** — ذخیره‌ی IP، پورت، نام کاربری و رمز عبور
- **ذخیره‌سازی امن رمزها** — رمز عبورها با AES-256-GCM رمزنگاری می‌شوند و کلید اصلی توسط
  کیچین ویندوز (DPAPI) محافظت می‌شود؛ هیچ رمزی روی دیسک به‌صورت ساده ذخیره نمی‌شود
- **پشتیبانی از پراکسی** — SOCKS4/SOCKS5 و HTTP CONNECT، قابل تنظیم به‌صورت جداگانه برای هر سرور
- **SFTP** — مرورگر فایل مانند Explorer ویندوز با آپلود/دانلود Drag & Drop، پوشه‌ی جدید،
  تغییر نام و حذف
- **انتقال بازگشتی** — آپلود و دانلود کامل پوشه‌ها به‌صورت بازگشتی با نمایش پیشرفت
- **۶ تم** — منظم، طوسی، روشن، دراکولا، سولارایزد، گرووباکس (همزمان برای رابط کاربری و ترمینال)
- **کپی هنگام انتخاب** — انتخاب متن در ترمینال به‌طور خودکار آن را کپی می‌کند
- **تأیید قبل از بستن تب** — جلوگیری از بستن تصادفی نشست‌های متصل
- **رابط راست‌چین فارسی** — تمام متن‌ها و میانبرها فارسی هستند

## میانبرهای کیبورد

| میانبر | عملکرد |
|---|---|
| `Ctrl + N` | سرور جدید |
| `Ctrl + T` | زبانه‌ی ترمینال جدید |
| `Ctrl + W` | بستن زبانه‌ی فعلی |
| `Esc` | بستن پنجره‌ی باز |

## نصب

### نسخه‌ی آماده (پیشنهادی)

دو نسخه از [صفحه‌ی Releases](https://github.com/Mahdips/PersiaSSH/releases) دانلود کنید:

- **`PersiaSSH-Setup-1.1.0.exe`** — نصب‌کننده: میان‌بر روی دسکتاپ و منوی استارت می‌سازد
- **`PersiaSSH-Portable-1.1.0.exe`** — نسخه‌ی قابل حمل: نیازی به نصب ندارد، روی فلش مموری کار می‌کند

### اجرای کد

نیاز به [Node.js](https://nodejs.org) نسخه‌ی ۱۸ یا بالاتر:

```bash
git clone https://github.com/Mahdips/PersiaSSH.git
cd PersiaSSH
npm install
npm start
```

### ساخت نصب‌کننده‌ی ویندوز

```bash
npm run dist            # نصب‌کننده + نسخه‌ی قابل حمل
npm run dist:portable   # فقط نسخه‌ی قابل حمل
```

خروجی در پوشه‌ی `dist/` ساخته می‌شود.

## تست

دو مجموعه‌تست یکپارچه وجود دارند که کل مسیر داده‌ای واقعی را با سرورهای شبیه‌سازی‌شده‌ی واقعی
(ssh2 در حالت سرور + SOCKS5/HTTP proxy واقعی) امتحان می‌کنند:

```bash
npm test
```

- `test/stack_test.js` — تونل مستقیم، تونل SOCKS5، احراز هویت SSH و اجرای دستور
- `test/sftp_test.js` — تونل HTTP CONNECT، READDIR، خواندن فایل، STAT و MKDIR

این تست‌ها فقط **توپولوژی شبکه** را شبیه‌سازی می‌کنند — همان کد تولیدی که برنامه استفاده می‌کند
(`proxy.js`، `sessions.js`، `sftp.js`) در برابر سرورهای واقعی SSH آزمایش می‌شود.

```
PersiaSSH/
├── src/
│   ├── main.js            # نقطه‌ی ورود الکترون، پنجره‌ها و منو

│       ├── sessions.js    # نشست‌های SSH و PTY
│       ├── sftp.js        # انتقال فایل بازگشتی
│       ├── sftpWindow.js  # پنجره‌ی مرورگر فایل
│       └── ipc.js         # تمام هندلرهای ipc
├── renderer/
│   ├── index.html         # رابط اصلی (ترمینال + لیست سرورها)
│   ├── sftp.html          # مرورگر فایل
│   ├── css/               # استایل و تم‌ها
│   └── js/                # منطق رابط

```

## امنیت

رمز عبور سرورها هرگز به‌صورت متن ساده ذخیره نمی‌شود. آن‌ها با AES-256-GCM رمزنگاری می‌شوند و
کلید اصلی توسط Data Protection API ویندوز (به‌همراه کاربر فعلی) محافظت می‌شود. در نتیجه:

- خواندن رمزها روی یک سیستم یا حساب کاربری دیگر غیرممکن است
- هیچ رمزی در کد منبع یا فایل‌های تنظیمات به‌صورت ساده وجود ندارد
